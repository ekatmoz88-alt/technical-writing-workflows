# Technical Writing Workflows — обзор проекта

Docs-as-Code демонстрация автоматических проверок OpenAPI, Markdown и ссылок
для вымышленного Tasks API.

## Файлы проекта

- [OpenAPI contract](../openapi/openapi.yaml)
- [Tasks API overview](tasks-api-overview.md)
- [Lint workflow](../.github/workflows/lint.yml)
- [Pages workflow](../.github/workflows/pages.yml)

## Инструменты

Spectral проверяет OpenAPI, markdownlint — Markdown, Lychee — ссылки.
Точные параметры команд определяются workflow.
